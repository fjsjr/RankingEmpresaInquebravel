# Story 1.1 — Sistema de Ranking Empresa Inquebrável

**Status:** Done
**Epic:** 1 — Sistema de Ranking de Eventos
**Story:** 1.1

## Descrição

Como organizador do evento Empresa Inquebrável, quero um sistema de ranking em tempo real para grupos, podendo adicionar pontuação manualmente e via análise da IA, usando Supabase como banco de dados.

## Acceptance Criteria

- [x] Backend Node.js com Express expondo API REST
- [x] Conexão com Supabase (PostgreSQL)
- [x] CRUD de grupos com nome e cor personalizada
- [x] CRUD de participantes por grupo
- [x] Adição de pontuação manual pelo admin
- [x] Análise de atividades por IA (Claude API) com sugestão de pontuação
- [x] Confirmação e salvamento da pontuação sugerida pela IA
- [x] Tela de ranking público com pódio (Top 3) e lista completa
- [x] Atualização em tempo real via Supabase Realtime
- [x] Painel admin protegido por senha
- [x] Histórico de pontuações por grupo

## File List

### Criados
- `package.json` — Dependências e scripts
- `src/server.js` — Servidor Express principal
- `src/config/supabase.js` — Cliente Supabase (admin + anon)
- `src/middleware/auth.js` — Middleware de autenticação admin
- `src/routes/groups.js` — Rotas de grupos e participantes
- `src/routes/scores.js` — Rotas de pontuação (manual + IA)
- `src/routes/config.js` — Rota de configuração pública
- `src/services/ai-analyzer.js` — Serviço de análise IA (Claude API)
- `public/index.html` — Tela de ranking público (ao vivo)
- `public/admin.html` — Painel administrativo
- `public/css/style.css` — Estilos completos
- `supabase/migrations/001_initial_schema.sql` — Schema do banco
- `.env.example` — Variáveis de ambiente exemplo

## Notas Técnicas

- Usa ESM (`"type": "module"`)
- Supabase Realtime para atualizações ao vivo no ranking público
- Claude claude-sonnet-4-6 para análise de atividades
- Rate limiting nas rotas de IA (20 req/min)
- Autenticação admin via header `x-admin-password`
